## REQ-01 登录与会话管理
用户可以登录和退出。应用保存当前会话状态，在页面刷新后恢复登录状态，并在会话失效时安全退出。

## REQ-02 邮件业务访问
已登录用户可以通过邮件服务接口访问邮件相关功能。邮件请求使用统一的 API 调用入口和当前会话凭证。

## REQ-03 实时连接
应用可以建立邮件相关的 WebSocket 连接，并在会话状态变化时更新连接凭证或关闭连接。

## REQ-04 应用启动与开发配置
应用入口负责初始化会话状态和路由。开发环境提供前端服务以及 API 和 WebSocket 的代理配置。
